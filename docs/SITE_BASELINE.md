## Материалы эталона

Каталог: `baseline/2026-09-29/`.

- `inventory.json` — перечень всех 74 HTML-страниц (73 публичные + admin), заголовки, секции, подключения CSS/JS.
- `manifest.json` — SHA-256 для 205 файлов: страницы, стили, скрипты, изображения, генераторы, серверы и тесты. Включён новый проверочный скрипт; документация и скриншоты не входят. Это обнаружение изменений, **не резервная копия содержимого**.
- `screenshots.json` — условия визуальной фиксации и перечень снимков.
- По два полных снимка для главной, каталога, отрасли, объекта, услуги и пустой панели администратора: 390 и 1440 px, высота окна 900 px. Ключевые страницы: `objects/medicine.html`, `objects/dentistry.html`, `services/klopy.html`.

Снимки сделаны в Chromium, на русском языке, с уменьшенным движением, свежим хранилищем и заблокированными внешними запросами, включая Google Fonts и аналитику. Использован системный запасной шрифт. Панель снята с подставленным пустым API; данных клиентов нет. На полных снимках фиксированные элементы отображаются в положении исходного окна — для оценки перекрытий дополнительно смотреть обычный viewport и прокрутку в браузере.

Это визуальная опора для сравнения, а не автоматический пиксельный тест. При новой правке сначала снять актуальное «до», сохранив согласованные изменения после этой даты. Нельзя откатывать последующие функции только потому, что их нет на старом снимке.

## Как проверить сохранность

```sh
python tools/check_baseline.py
python tools/audit_public.py
npm test
```

Первый инструмент ничего не записывает. Выводит `CHANGED`, `MISSING`, `ADDED` в отслеживаемых областях. Код 0 означает совпадение байтов, 1 — отличия для рассмотрения (не обязательно ошибка), 2 — проблему чтения эталона. Замена окончаний строк тоже меняет хеш. Новые области вне шаблонов `patterns` дополнительно проверять через Git.

Изменения, требуемые задачей, допустимы. Каждое постороннее отличие требует разбора, а не автоматического отката всего файла. Для восстановления содержимого нужны Git/резервная копия: хеш и снимок его не восстанавливают.
