# Dis Cleaning

Сайт дезинфекции, контроля вредителей для Алматы на Next.js App Router.
Телефон и WhatsApp: **+7 707 620 38 13**.

## Сохранение текущей основы

Перед любой правкой прочитать [AGENTS.md](AGENTS.md): новый функционал добавляется точечно, без переписывания сайта и изменения уже принятого оформления вне задачи.

- [Зафиксированная основа и визуальные эталоны](docs/SITE_BASELINE.md).
- [Карта страниц, источников, стилей и генераторов](docs/ARCHITECTURE.md).
- `python tools/check_baseline.py` — отчёт об изменениях относительно основы от 29.09.2026; ничего не перезаписывает. Отличия от исторической версии нужно сопоставить с текущей задачей, а не автоматически откатывать.

## Запуск

```sh
npm ci
npm run dev
```

Node.js 20.9 или новее. Режим разработки: http://localhost:8080/.

Production:

```sh
npm run build
npm start
```

Открыть http://localhost:8080/. Основные адреса работают без `.html`; прежние известные адреса перенаправляются на них. `public/` заполняется ресурсами автоматически перед dev/build; исходные HTML туда не копируются. Сохранённая статическая версия в корне по-прежнему открывается с диска; `npm run legacy:serve` запускает её прежним сервером. Основной сайт использует JSX, а не эти HTML.

## Содержание

- Главная: большой слайдер из трёх сюжетов, каталог объектов, услуги, методы, FAQ и контакты.
- `/objects`: 11 отраслевых разделов и 39 типов объектов; каждая отрасль и каждый объект имеют собственную страницу в `objects/`.
- `services/`: 17 страниц санитарных обработок, включая дезинфекцию помещений. Короткие описания, порядок работ, подготовка, стоимость и форма заявки.
- Команда и сертификаты не выводятся; исходные изображения сохранены. Реквизиты удалены из публичных страниц и активной конфигурации.
- RU/KZ: переключение основных элементов интерфейса и слайдера. Подробные описания услуг и объектов пока на русском языке.

## Редактирование

Общее оформление: `css/theme.css` и `css/catalog.css`. Контент: `content/pages/*.jsx`. Общий каркас: `components/SiteHeader.jsx`, `components/SiteFooter.jsx`. Поведение: `lib/site-interactions.js`. Контакты и словари: `lib/site-config.js`. Метаданные и JSON-LD: `content/seo.json`.

Прежняя мини-игра удалена по указанию владельца и при переносе не восстанавливалась.

Старые `tools/objects_data.py`, `tools/service_copy.py`, `tools/services_data.py` сохранены как источники исторической статической версии. Следующие команды изменяют только прежний HTML и не обновляют Next.js:

```sh
python tools/build_catalog.py
python tools/sync_layout.py
```

Не запускать старые генераторы для обновления Next-сайта. Редактировать JSX напрямую. `tools/migrate-next.py` использовался для однократного импорта принятого HTML; он не перезаписывает существующие JSX. Карта текущих источников — в [ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Проверки

```sh
python tools/audit_public.py
npm run build
npm test
```

Playwright запускает production Next.js на отдельном порту 8082 (переопределение: `TEST_PORT`) и проверяет все 70 публичных страниц на ширинах 320, 390, 768, 1024, 1440 и 1920 px, JavaScript, ресурсы, формы, WhatsApp, слайдер, меню, RU/KZ, SEO, React-панель и API. Серверные тестовые заявки записываются в отдельную временную папку. Скриншоты сохраняются в `artifacts/`.

При запущенном Next-сервере: `python tools/audit_next.py http://127.0.0.1:8080` проверяет именно его страницы, ресурсы и якоря. `audit_public.py` проверяет оставленную статическую версию. Отчёт о переносе: [NEXT_MIGRATION.md](docs/NEXT_MIGRATION.md).

## Формы

Форма открывает WhatsApp с подготовленным текстом. Посетитель сам отправляет сообщение менеджеру. Копия формы сохраняется в localStorage этого браузера; она не является доставленной заявкой и не синхронизируется между устройствами. Автотесты подменяют открытие WhatsApp и не отправляют сообщения.

`/admin` — локальная панель на React; публичная форма не вызывает серверный `/api/order`. API реализован в `app/api/`, хранит `leads.json` вне `public/`; путь можно изменить через `LEADS_FILE`. Для этого API нужен Node-сервер с постоянным доступным для записи диском. Статусы и удаление в панели, как раньше, сохраняются локально. Общая CRM требует отдельной настройки доступа и доставки.

## Изображения

Три новых изображения для слайдера созданы встроенным imagegen. Исходные запросы и пути записаны в `images/GENERATION.md`. Это иллюстративные сцены, а не фотографии выполненных заказов или объектов клиентов.

Для 11 карточек отраслей дополнительно созданы изображения `images/objects/*.jpg` встроенным imagegen. Полные запросы и имена файлов: `images/objects/prompts.json`. Карточки используют формат 4:3 и отложенную загрузку изображений на главной и в каталоге.

Оформление методов, преимуществ и этапов: `css/features.css`. Иллюстрации методов находятся в `images/icons/`, иконки преимуществ и этапов встроены в HTML. Для повторного применения декора к исходной главной: `python tools/style_home_features.py` (повторный запуск не дублирует элементы).

Изображения методов заменены фотореалистичными сценами оборудования и процесса в `images/methods/`. Сгенерированы встроенным imagegen; это иллюстрации, а не фотографии выполненных заказов. Полные запросы и файлы: `images/methods/prompts.json`. Иконки преимуществ и этапов сохранены.

## Публикация на Plesk / Apache

`npm run export:hosting` создаёт свежий архив в `artifacts/publication-*/discleaning.kz-hosting.zip`. Требуются Node.js и Python. Сборка выполняется отдельно от рабочего проекта. В архив входят 70 публичных страниц, ресурсы и `.htaccess` для чистых URL и перенаправлений старых `.html`-адресов. API и панель администратора требуют Node.js и в статический архив не входят.

Сохраните резервную копию действующей публикации, распакуйте архив в `httpdocs` с заменой, включая `_next` и `.htaccess`. Plesk должен передавать чистые адреса в Apache с включённым mod_rewrite. Проверьте `/objects`, `/services/klopy` и переход со старого `/services/klopy.html`. Если ещё остались старые страницы `services/cleaning.html`, `services/zapakh.html`, `services/kroty.html`, `services/zmei.html`, удалите их после резервного копирования: новый архив их не содержит.
