# Dis Cleaning — Служба профессиональной дезинфекции и клининга

Современный, полностью автономный сайт службы дезинфекции, дезинсекции, дератизации и клининга для компании **Dis Cleaning** (ИП «ФЁДОРОВ ДАНИЛ СЕРГЕЕВИЧ»).

Дизайн и айдентика сайта переработаны в точном соответствии с фирменным стилем логотипа:
- **Фирменные цвета**: Royal Azure Blue (`#0066cc`, цвет дома и «Dis») + Leaf Eco Green (`#16a34a`, цвет листьев и «Cleaning») + Sparkle Cyan (`#38bdf8`, цвет сияющих звёзд чистоты).
- **Формы и элементы**: органичные скругления карточек (`border-radius: 16px–24px`), мягкие градиенты, акцентные бейджи и кнопки с подсветкой.

## 🌟 Возможности и функционал сайта

### 1. Каталог услуг (19 направлений)
- Уничтожение клопов, тараканов, блох, комаров, муравьёв, клещей, моли, мокриц, чешуйниц, кожееда, пауков и ос.
- Выведение грызунов (крыс, мышей), кротов, змей.
- Уничтожение плесени, грибка, устранение неприятных запахов (дезодорация).
- Комплексная обработка участков и открытых территорий (с реалистичной фотографией [`images/svc-yard.jpg`](file:///d:/Anti-Gravity/Site_Disinfection/images/svc-yard.jpg)).
- Все 19 карточек услуг с бейджами, тегами и кнопкой быстрой заявки.

### 2. Мультиязычность (RU / KZ)
- Мгновенное переключение языка между **Русским** и **Казахским** без перезагрузки страницы.
- 100% покрытие словаря (218 текстовых ключей интерфейса).
- Автоматическое сохранение выбранного языка в `localStorage`.

### 3. Интерактивные элементы и UX
- **Модальное окно заявки**: вызов мастера с выбором услуги, типа объекта (квартира, дом, офис, склад, ресторан и др.), площади в м² и описанием проблемы.
- **Умная предвыборка услуги**: при клике на любую услугу в каталоге, она автоматически подставляется в форму модального окна.
- **Маска ввода телефона**: автоматическое форматирование номера `+7 (7XX) XXX-XX-XX` при вводе.
- **Интеграция с WhatsApp**: автоматическая генерация красиво отформатированного сообщения с эмодзи и переход в чат менеджера.
- **Сертификаты и Lightbox**: 4 официальных сертификата с открытием во весь экран, зумом и закрытием по клику/Esc.
- **Аккордеон FAQ**: раскрывающиеся вопросы и ответы с плавной анимацией.
- **Мобильное меню (Burger)** и **Нижний бар быстрых действий (MBB)** для смартфонов.
- **Кнопка возврата наверх** с плавным скроллом.

### 4. Встроенная CRM / Панель администратора (`admin.html`)
- Локальное сохранение всех поступающих заявок в базу (в `localStorage` и в файл `leads.json` на сервере).
- Заявки сохраняются автоматически, даже если у клиента нет WhatsApp.
- Интерфейс для просмотра входящих заявок, фильтрации по статусам («Новая», «В работе», «Завершена», «Отклонена»), поиска по номеру и имени.
- Возможность экспорта базы заявок в **Excel / CSV** в один клик.

## 🚀 Как запустить сайт

### Способ 1: Прямое открытие без сервера
Просто дважды кликните по файлу `index.html` в проводнике Windows. Сайт откроется в вашем браузере и будет работать полностью автономно.

### Способ 2: Через Node.js (рекомендуется для разработки)
```bash
npm start
```
или:
```bash
node server.js
```
Сайт будет доступен по адресу: **http://localhost:8080/**  
Панель администратора: **http://localhost:8080/admin.html**

### Способ 3: Через Python
```bash
python server.py
```
или с указанием другого порта:
```bash
python server.py 3000
```
